# 💻 SQL Showcase

One of the advanced SQL analyses in this project ranks sales agents using a Common Table Expression (CTE) and a Window Function.

```sql
WITH RankedSales AS (
    SELECT
        sales_agent,
        SUM(close_value) AS total_revenue,
        COUNT(CASE WHEN deal_stage='Won' THEN 1 END) AS won_deals,
        COUNT(CASE WHEN deal_stage='Lost' THEN 1 END) AS lost_deals,
        ROUND(
            COUNT(CASE WHEN deal_stage='Won' THEN 1 END)
            *100.0/COUNT(*),
            2
        ) AS win_rate,
        DENSE_RANK() OVER(
            ORDER BY SUM(close_value) DESC
        ) AS agent_rank
    FROM sales_pipeline
    GROUP BY sales_agent
)

SELECT *
FROM RankedSales
WHERE agent_rank <= 5;
```

### SQL Concepts Demonstrated

- Common Table Expressions (CTEs)
- Aggregate Functions
- Window Functions
- Ranking
- Conditional Aggregation
- Business KPI Calculation
